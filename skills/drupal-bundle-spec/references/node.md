# Content type settings

```
* Name: `Web page`
* Machine name: `web_page`
* Description: `Use to create new pages in the website.`
* Preview before submitting: Yes/No
* Publishing options:
    * Published: Yes/No
    * Promoted to front page: Yes/No
    * Sticky at top of lists: Yes/No
    * Create new revision: Yes/No (Default Yes)
* Enable translation: Yes/No
* Display author and date information: No
* Available menus: None
```

- Do not add Display author and date information unless the requirements ask for it.
- When the site uses content moderation, name the workflow (e.g. `editorial`) under Publishing options.
