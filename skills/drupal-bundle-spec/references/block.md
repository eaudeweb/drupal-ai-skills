# Custom block type settings

```
* Label: `Call to action`
* Machine name: `call_to_action`
* Description: `A short text with a button linking to a page.`
* Create new revision: Yes/No (Default Yes)
* Enable translation: Yes/No
* Placement: Block layout / Layout Builder / Referenced from a field
* Reusable: Yes/No
```

- **Placement** - where the blocks are used. For Block layout, name the theme regions. For a field reference, name the field and module (e.g. `block_field`, Entity reference).
- **Reusable** - No for blocks created inline in Layout Builder, which exist only on one page and do not appear in the Custom block library.
- The block label field is `info`. State whether the block title is displayed.
